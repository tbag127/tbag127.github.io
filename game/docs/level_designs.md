# Super Forbidden Game - Level Designs

## Level 1: The Awakening

### Overview
A mysterious school campus after hours where Hang Yi discovers his telekinesis powers while trapped inside. The level introduces basic game mechanics and character abilities.

### Map Layout
```
+-----------------------------------+
|                                   |
|  START                            |
|   |                               |
|   v                               |
|  [Classroom A]----[Hallway 1]     |
|       |               |           |
|       |               |           |
|  [Library]------[Main Hall]       |
|                      |            |
|                      |            |
|  [Science Lab]---[Hallway 2]      |
|       |               |           |
|       |               |           |
|  [Computer Room]--[EXIT]          |
|                                   |
+-----------------------------------+
```

### Key Areas

#### Classroom A (Starting Area)
- **Puzzle**: Tutorial area teaching basic movement
- **Objects**: Desks, chairs, books
- **Objective**: Learn to use telekinesis to move a desk blocking the door

#### Hallway 1
- **Puzzle**: Stack boxes to reach a ventilation shaft
- **Objects**: Storage boxes, maintenance ladder
- **Objective**: Create a path to the Main Hall

#### Library
- **Puzzle**: Retrieve a key from a high shelf
- **Objects**: Bookshelves, rolling ladder, books
- **Objective**: Use telekinesis to manipulate objects and reach the key

#### Main Hall
- **Encounter**: Meet Xin Na who demonstrates time manipulation
- **Puzzle**: Pass through a security gate that closes too quickly
- **Objects**: Security gate, timer mechanism
- **Objective**: Learn to use Xin Na's time slow ability

#### Science Lab
- **Puzzle**: Chemical reaction puzzle
- **Objects**: Beakers, chemicals, safety equipment
- **Objective**: Use telekinesis to mix chemicals in the right order while using time slow to prevent an explosion

#### Hallway 2
- **Puzzle**: Navigate past moving laser security system
- **Objects**: Laser emitters, mirrors, control panel
- **Objective**: Use time slow to safely pass through, or use telekinesis to redirect lasers

#### Computer Room
- **Puzzle**: Final puzzle combining both abilities
- **Objects**: Computer terminals, security panels, moving platforms
- **Objective**: Hack the security system to unlock the exit while dealing with time-sensitive elements

#### EXIT
- Level completion point

## Level 2: The Challenge

### Overview
An ancient temple with elemental trials where Ji Kairui tests Hang Yi and Xin Na's mastery of their abilities.

### Map Layout
```
+-----------------------------------+
|                                   |
|  START                            |
|   |                               |
|   v                               |
|  [Entrance Hall]                  |
|       |                           |
|       |                           |
|  [Fire Chamber]---[Water Chamber] |
|       |               |           |
|       |               |           |
|       +-----[Central Chamber]     |
|                      |            |
|                      |            |
|  [Time Trial]----[Telekinesis     |
|       |           Challenge]      |
|       |               |           |
|       +-----[Final Chamber]       |
|                      |            |
|                      v            |
|                     EXIT          |
|                                   |
+-----------------------------------+
```

### Key Areas

#### Entrance Hall
- **Encounter**: Meet Ji Kairui who introduces elemental powers
- **Puzzle**: Simple demonstration of fire and water elements
- **Objects**: Torches, water pools, elemental switches
- **Objective**: Learn to use Ji Kairui's elemental abilities

#### Fire Chamber
- **Puzzle**: Navigate through a room with ice barriers and fire hazards
- **Objects**: Ice walls, fire pits, flammable objects
- **Objective**: Use fire element to melt ice, creating paths forward

#### Water Chamber
- **Puzzle**: Cross gaps using water bridges
- **Objects**: Water sources, channels, gaps in the floor
- **Objective**: Use water element to fill channels and create bridges

#### Central Chamber
- **Puzzle**: Activate an ancient mechanism using all three characters
- **Objects**: Elemental pedestals, moving platforms, timed gates
- **Objective**: Switch between characters to activate different parts of the mechanism

#### Time Trial
- **Puzzle**: Navigate through rapidly changing obstacles
- **Objects**: Moving walls, disappearing platforms, swinging pendulums
- **Objective**: Master Xin Na's time manipulation to navigate safely

#### Telekinesis Challenge
- **Puzzle**: Precisely position objects while dealing with environmental hazards
- **Objects**: Heavy stones, pressure plates, balance scales
- **Objective**: Demonstrate mastery of Hang Yi's telekinesis

#### Final Chamber
- **Puzzle**: Complex puzzle requiring all three abilities in sequence
- **Objects**: Elemental switches, time-sensitive platforms, telekinetically controlled objects
- **Objective**: Combine all powers to unlock the exit and complete the temple trials

#### EXIT
- Level completion point
