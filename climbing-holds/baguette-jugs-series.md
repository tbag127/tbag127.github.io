# 法棍大握点系列设计 (Baguette Jugs Series Design)

## 系列概述 (Series Overview)
参考360-092PU蛇形握点系列设计的四件套大握点（jugs）系列，每个握点都提供深度和安全的抓握体验。

## 握点系列 (Hold Series)

### 1. 法棍主握点 (Main Baguette Jug)
- 类型：Jug（主要大握点）
- 尺寸：280mm x 160mm x 110mm（2XL尺寸）
- 抓握方向：向下或水平
- 特点：
  - 深度碗状内部（110mm）
  - 宽大的唇缘提供安全保护
  - 适合作为起点或休息点
  - 双手抓握设计

### 2. 法棍弧形握点 (Curved Baguette Jug)
- 类型：Jug（弧形大握点）
- 尺寸：240mm x 140mm x 100mm（2XL尺寸）
- 抓握方向：45度角
- 特点：
  - 弧形设计便于动态动作
  - 深度内凹（100mm）
  - 流畅的过渡曲线
  - 适合单手大动作

### 3. 法棍侧握点 (Side Baguette Jug)
- 类型：Jug（侧向大握点）
- 尺寸：220mm x 130mm x 95mm（2XL尺寸）
- 抓握方向：侧向
- 特点：
  - 侧向深度抓握设计
  - 适合横向移动
  - 手指位置槽设计
  - 单手抓握最佳

### 4. 法棍迷你握点 (Mini Baguette Jug)
- 类型：Jug（小型大握点）
- 尺寸：180mm x 120mm x 90mm（2XL尺寸）
- 抓握方向：多向性
- 特点：
  - 紧凑但深度充足
  - 适合过渡动作
  - 全方位抓握设计
  - 灵活的定位选择

## 共同特性 (Common Features)
- 材质：360PU高品质树脂
- 表面处理：
  - 抓握区：光滑无纹理
  - 外部：细腻平整
- 边缘处理：25mm大半径圆滑过渡
- 固定系统：螺丝固定（3/8英寸）
- 使用场景：初级到中级路线
- 安全特性：
  - 所有边缘大半径处理
  - 深度足够的抓握空间
  - 稳定的固定系统
  - 防滑表面处理
