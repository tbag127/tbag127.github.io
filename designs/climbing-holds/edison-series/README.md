# Edison Light Bulb Climbing Hold Series

This directory contains the design files and specifications for the Edison-inspired climbing hold series.

## Design Concepts
- Classic Edison light bulb shapes
- Dual texture surfaces
- Multiple size variations
- Historical accuracy in design details

## File Structure
- `3d-models/` - Contains Blender files and exported 3D models
- `renders/` - High quality renders of the designs
- `specifications/` - Technical specifications and measurements
